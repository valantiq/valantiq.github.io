gmail-multi-mcp

Application information · Last updated 27 October 2026

What this application is

gmail-multi-mcp is a small, read-only tool that runs on its owner's own computer. It lets the owner's AI assistant search and read the owner's own Gmail mailboxes, for example a personal Gmail account and a work account together, when the owner asks it to.

It is operated by Valantiq Limited as a personal tool. It is not a hosted service, has no public user base, and has no servers that receive anyone's email. It only works for the Google accounts of the person running it.

The one permission it requests

The application requests a single Google OAuth scope:

https://www.googleapis.com/auth/gmail.readonly, shown by Google as "View your email messages and settings".

This is needed so the owner can ask questions such as "find the invoice from last week" across their accounts. The application can read messages, conversations, labels and existing drafts. It cannot send, delete, modify, label or archive mail, and it requests no other Google permission.

How data is handled

  • Email is read from Google only when the owner asks, and is processed on the owner's computer.
  • The application does not send email content to the developer or to any server operated by the developer.
  • It does not store email content. It stores only the sign-in credential (a refresh token) in the owner's operating-system keychain, plus a local list of the owner's account names and a local activity log that contains no email content.
  • Email text the owner's AI assistant reads is processed by that assistant's provider under the provider's terms, at the owner's direction. See the Privacy Policy for details.
  • The owner can disconnect at any time and revoke access at myaccount.google.com/permissions.

gmail-multi-mcp's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
